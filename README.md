# Midas
Project repo for the JPMC Advanced Software Engineering Forage program

• Built Kafka consumers for transaction processing.
• Implemented business logic and database operations using Spring Boot, JPA, and H2.
• Integrated an external REST API to process transaction incentives.
• Developed RESTful endpoints for balance inquiries.
• Validated functionality through automated testing and debugging.
This program strengthened my understanding of backend development, event-driven systems, API integration, and enterprise software architecture.
